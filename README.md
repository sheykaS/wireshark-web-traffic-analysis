# Wireshark Web Traffic Analysis

Wireshark, Excel and Power BI beginner-friendly network traffic analysis project.

# Project Overview

This is an example project that examines the traffic on a website hosted locally on the web. The network packets were captured and analysed using Wireshark, network data captured was analysed in Excel and the result was presented in a visual dashboard using Power BI.

# Purpose

Overall, this project was aimed at providing hands-on experience in:

Using the same interface as the host.Using the same interface as the host machine.
Know how to explain the relationship between TCP and HTTP communication.
Analyzing packet information
Finding the HTTP request and response in an email.
Calculating packet statistics
Creating a network traffic dashboard
A technical project that will be documented and presented.

# Project Process

1. Developed a basic HTML web page.
2. Developed the website using the IntelliJ IDEA.
3. Analyzed the captured traffic in Wireshark.
4. Searched for the captured packets and analyzed them in Wireshark.
5. Analyzed TCP, HTTP and WebSocket traffic.
6. Exported packet data to CSV.
7. Analyzed the data using Excel.
8. Created a Power BI dashboard.
9. Wrote documentation for the project and shared it on GitHub.
